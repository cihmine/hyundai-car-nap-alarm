# 휴식모드

**주차한 차에서 쉬는 동안 기상 시각에 깨워 주고, 배터리가 정해 둔 보존량에 닿기 전에 먼저 깨워 장치를 꺼 주는 앱**입니다. 전기차와 내연기관차(+캠핑 배터리)를 하나의 앱으로 지원합니다. Pleos Connect용.

> 현대자동차그룹 차량용 앱 개발 공모전 출품작 · 시제품

## 30초 체험

첫 화면 하단바의 **캠핑 · 영화관 · 낮잠 · 충전 대기(전기차만)** 를 누르면 옆 창이 열리고, 창의 큰 버튼으로 켜고 끕니다. 켜면 저장해 둔 설정(실내등, 시트, 라디오)이 한 번에 적용되고 **끄고 원래대로** 를 누르면 되돌아갑니다. 모드 설정은 창 안에서 바로 바꾸고, **＋** 로 모드를 추가할 수 있습니다. 가운데 원은 전기차 배터리(차량 실제 값), 오른쪽 위는 남길 배터리까지 예상 시간과 주행 가능 거리입니다. 시트 자세와 라디오는 모의이고, 실내등은 명령을 보내지만 에뮬레이터에서는 값이 바뀌지 않습니다.

- **낮잠**: 타이머 + 배터리 보호 감시. 남길 배터리(% 또는 km)에 닿기 전에 먼저 깨우고 장치를 꺼요.
- **충전 대기**: 타이머 없이 충전률만 감시하다 목표(80·90·100%, ±5)에 닿으면 알람. 휴게소 급속충전 중 차에서 기다릴 때.

1. APK 를 설치하고 앱을 엽니다(Pleos Connect 에뮬레이터 또는 Android Automotive).
2. 오른쪽 위 **◂ 시연 패널** 을 열고 **"장면 1 · 전기차 전력 보호"** 를 누릅니다. 나머지는 자동으로 진행되며, 화면 맨 위 노란 띠가 지금 단계를 설명합니다.
   - 소비 1.5kW → **남은 시간 12시간**, 공조를 세게(3kW) → **6시간** (계산식이 화면에 그대로 나옴)
   - 보존량 근처로 이동(시간 단축) → **기상 시각보다 먼저 알람**
   - 배터리 소모 30배속 → 보존량 30%에 닿으면 **모의 공조 종료**, '5분 더'를 눌러도 한도는 그대로
   - '확인하고 휴식 끝내기' → 앱이 바꾼 시트·실내등은 원래대로, 보호로 끈 공조는 **자동으로 다시 켜지 않아요**
3. **장면 2**(내연기관차 + 캠핑 배터리: 800Wh·조명 100W → 6시간 → 모의 조명 종료), **장면 3**(12V 만 있는 차: **"계산 불가"**, 그래도 20초 뒤 알람), **장면 4**(충전 대기: 72% → 모의 50kW 충전·30배속 → **80%에서 알람**)도 같은 방식입니다.

시연 장면의 전원 값·장치는 **모의**이며 화면에 그렇게 표시합니다(계산 자체는 실제). 장면 밖에서는 전기차 충전률·용량·주행 가능 거리를 차량 SDK 에서 실제로 읽습니다.

## 코드 지도

| 파일 | 하는 일 |
|---|---|
| [`core/.../Energy.kt`](core/src/main/kotlin/com/cihmine/napalarm/core/Energy.kt) | 전원 3종, **남은 사용 시간 계산**(RuntimeEstimator), **전력 보호 판단**(EnergyGuard) — 파일 맨 위에 흐름 그림 |
| [`core/.../NapEngine.kt`](core/src/main/kotlin/com/cihmine/napalarm/core/NapEngine.kt) | 휴식 타이머 상태 전이(휴식 → 알람 → 다시 알림 → 복구), 재시작 복원, 전력 감시 연결 |
| [`core/.../VehicleControl.kt`](core/src/main/kotlin/com/cihmine/napalarm/core/VehicleControl.kt) | 공조·시트 요청 상태, **복구 규칙**(앱이 바꾼 것만, 직접 바꾼 값·보호로 끈 장치는 건드리지 않음) |
| [`core/.../RestModes.kt`](core/src/main/kotlin/com/cihmine/napalarm/core/RestModes.kt) | 하단바 모드(캠핑·영화관·낮잠·충전 대기·추가 모드), 켜고 끌 때 적용·되돌릴 값 |
| [`core/src/test/.../EnergyTest.kt`](core/src/test/kotlin/com/cihmine/napalarm/core/EnergyTest.kt) | 계획서 검증 사례 N-T11~N-T18 (테스트 이름이 곧 규칙) |
| [`core/src/test/.../ChargeWakeTest.kt`](core/src/test/kotlin/com/cihmine/napalarm/core/ChargeWakeTest.kt) | 충전 대기: 목표 충전률을 아래에서 위로 넘을 때 한 번 알림(N-T19) |
| [`app/.../NapController.kt`](app/src/main/kotlin/com/cihmine/napalarm/NapController.kt) | 화면·소리·모의 장치를 잇는 흐름, 시연 장면 1~4 |
| [`app/.../vehicle/MockEnergy.kt`](app/src/main/kotlin/com/cihmine/napalarm/vehicle/MockEnergy.kt) | 모의 전원(전기차·캠핑·12V)과 모의 장치 종료 |

**공조·시트·편의 장치 제어와 시연 장면의 전원 값은 모의입니다**(전기차 배터리 값은 차량 SDK 로 실제로 읽음). 화면 상단에 항상 "차량 연동 시뮬레이션"을 표시하며, 실제 차량 제어 어댑터는 이 빌드에 없습니다. 경적·원격 시동은 구현하지 않았습니다. 이 앱은 기상이나 차 안 체류 안전을 보장하는 장치가 아니며, 앱이 켜져 있고 차량 시스템이 깨어 있을 때만 알람이 울립니다.

## 무엇이 실제로 동작하나

| 기능 | 상태 |
|---|---|
| 휴식 시간 설정(15·30·60분, 직접 조정 1~180분), 예상 알람 시각 | 실제 |
| 카운트다운 — 시작·목표 시각 기준(단조 시계), 화면을 다시 그려도 초기화 안 됨 | 실제 |
| 알람 소리(작게 시작해 점점 크게), 기상 확인·5분 다시 알림 | 실제 |
| 앱이 꺼졌다 켜지면 남은 시간 복원, 시간이 지났으면 "알람이 울리지 않았어요"로 표시·기록 | 실제 |
| 재부팅·시각 변경 감지 시 일정 다시 확인 | 실제 |
| 하단바 모드 — 실내등·라디오·시트를 한 번에 적용하고 끄면 원래대로, 모드 추가·삭제(최대 5개) | 실내등 명령은 실제(기어 P), 시트·라디오는 모의 |
| 충전 대기 — 타이머 없이 충전률 감시, 목표에 닿으면 알람(충전 중 신호 없이 충전률만으로 판단) | 판단은 실제(차량 충전률), 시연은 모의 충전 |
| 공조 온도·시트 자세 준비, 요청 상태(모의 적용됨/실패/응답 없음/차단됨) | 모의 차량 |
| 원래 설정 복구 — 앱이 바꾼 항목만, 사용자가 직접 바꾼 값은 덮어쓰지 않고 확인 | 규칙은 실제, 차량은 모의 |
| 휴대폰 "10분 전 준비" 예약 | 모의 이벤트 |
| 기록(계획 시간·실제 앱 세션 시간·종료 사유) — 수면 측정 아님 | 실제 |
| 차종 자동 판별(충전률·연료량 지원 여부), 남길 배터리(% 또는 km) 설정 | 실제(구성은 시연 패널에서도 바꿈) |
| 전기차 배터리 충전률·용량·주행 가능 거리 읽기(Vehicle SDK) | 실제, 시연 장면은 모의 값 |
| 소비 전력 — 공조(전원·에어컨·바람 세기)·실내등 상태를 읽어 어림 | 상태는 실제, 와트는 추정값 |
| 남은 장치 사용 시간 계산과 계산식 표시, 데이터 끊김·충전 중·소비 0 처리 | 계산은 실제, 전기차 잔량 외 전원 값은 모의 |
| 보호 기준 10분 전 먼저 깨우기, 보존량 도달 시 장치 종료·결과 확인(실패·응답 없음 구분) | 규칙은 실제, 장치는 모의 |
| 12V 시동 배터리 — 남은 시간 "계산 불가", 차량 경고 신호만 알림 | 규칙은 실제, 신호는 모의 |

자세한 범위는 [`docs/IMPLEMENTATION_STATUS.md`](docs/IMPLEMENTATION_STATUS.md), 검증 결과는 [`docs/TEST_REPORT.md`](docs/TEST_REPORT.md).

## 구조

```
core/            순수 Kotlin — NapEngine(타이머 상태 전이·재시작 복원·충전 대기), VehicleControl(제어 요청·복구 규칙), RestModes(모드), Texts
core/            Energy(전원·남은 시간·전력 보호·충전 판단), CabinLoad(소비 전력 어림), VehicleKind(차종 판별)
core/src/test/   계획서 검증 사례 N-T01~N-T19 단위 테스트 68개(가짜 시계로 시간·재부팅·시각 변경 재현)
app/             Compose 화면, 저장(원자적 JSON), 알람 소리, Pleos Vehicle SDK 읽기(배터리·기어·공조 상태·실내등), 모의 차량(MockCar), 시연 패널
```

## 실행

요구 사항: Android Studio(JDK 17 이상), Android SDK 36

```
./gradlew :core:test            # 단위 테스트
./gradlew :app:assembleRelease  # 서명 키(~/.android-keys/carvoicegame.properties)가 있으면 서명된 APK
```

테스트 환경: Pleos Connect v2.1.0 에뮬레이터(API 34, Automotive, 화면 2560×1440). 단위 테스트 68개 통과. 시연은 시연 패널의 "20초 타이머로 시작(시간 단축)"을 쓰며, 영상에도 시간 단축임을 표시합니다.

기록은 기기 안에만 저장되며 앱을 지우거나 데이터를 초기화하면 사라집니다.

[`apk/최태현_휴식모드_release.apk`](apk/최태현_휴식모드_release.apk) — release 서명 APK(버전 0.1.0, 약 23MB). Pleos Connect v2.1.0 에뮬레이터(2560×1440)에 설치해 실행을 확인했습니다.

adb install -r --user 10 apk/최태현_휴식모드_release.apk   # 확인한 명령(에뮬레이터 차량 사용자 10)
